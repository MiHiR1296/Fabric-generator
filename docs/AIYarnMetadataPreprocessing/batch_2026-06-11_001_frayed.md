## Metadata Problem

The AI JSON's core was close to the dense center, but its support band was much
too narrow for the visible frayed fibers:

```text
Original core:   733-787
Original extent: 731-790
```

That means the JSON basically described only the central strand body. In Blender
this risks the same issue seen in the first AI batch: Arc 1 dominates and Arc 2
does not get enough V range to display loose fiber detail.

- keep the lower-threshold 2% support band for Arc 2,

## Process Decision

This sample reinforces the current AI-only metadata rule:

- AI JSON can be kept for provenance.
- PNG alpha should drive render metadata.
- Arc 1 and Arc 2 need different detectors.
- AI yarns should carry explicit `texture_scale_u`.
- Scanned-yarn metadata stays untouched.

Before adding a UI flow, the next batch should run through this same logging
path so we can see whether these thresholds hold across more AI-generated
styles or whether the AI path needs a small set of presets.
